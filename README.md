PersonManager

Учебное веб-приложение для управления списком людей, разработанное на C# и ASP.NET Core MVC.

О проекте

Приложение позволяет управлять записями о людях: добавлять, редактировать, удалять и искать записи. Данные хранятся в PostgreSQL, работа с базой данных реализована с помощью Entity Framework Core.

Функциональность

Добавление, редактирование и удаление записей.

Валидация введённых данных.

Поиск по имени без учёта регистра.

Фильтрация по возрасту.

Сортировка по имени.

Модальные окна для добавления и редактирования записей.

## Запуск проекта

### Требования

- .NET 10 SDK
- PostgreSQL
- Visual Studio 2026 или другая совместимая среда разработки

### Инструкция

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/Boobonick89/PersonManager.git
   cd PersonManager
   ```

2. Настроить строку подключения к PostgreSQL в `appsettings.json`, указав параметры собственной базы данных. Не использовать чужие пароли и не публиковать свои учётные данные.

3. Восстановить NuGet-пакеты:

   ```bash
   dotnet restore
   ```

4. Применить миграции Entity Framework Core:

   ```bash
   dotnet ef database update
   ```

   Для выполнения команды может потребоваться инструмент `dotnet-ef`.

5. Запустить приложение:

   ```bash
   dotnet run
   ```

6. Открыть адрес, указанный в консоли после запуска приложения.
